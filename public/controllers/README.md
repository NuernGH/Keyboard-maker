# Modele kontrolerów (tylko podgląd)

`nice-nano-v2.stl` — nice!nano v2 na podstawie modelu Jordana Banasika (Woovie).
Źródło: https://github.com/Woovie/nicenano-v2-model (nice_nano.STL).
Licencja: CC0 1.0 Universal (domena publiczna), https://creativecommons.org/publicdomain/zero/1.0/

Używany wyłącznie w podglądzie 3D (nie trafia do eksportu STL/STEP).
Układ pliku: X w poprzek płytki (0…17,8), Y w górę (−0,2…3,1), Z wzdłuż płytki (0…33,8), gniazdo USB po stronie +Z.
Model przeskalowany (2026-11-06) do wymiarów zmierzonych suwmiarką na płytce: 17,8 × 33,8 mm razem z USB,
płytka 33,0 × 1,2 mm, USB-C osadzone we wcięciu płytki, spodem równo ze spodem płytki, wystaje 0,8 mm,
razem 3,3 mm grubości (gniazdo od −0,2 do 3,1, Y = 0 to spód płytki). Oryginał Woovie: płytka 33,10 × 0,8, USB wystaje 1,52, razem 3,2.
