# Controller models (preview only)

`nice-nano-v2.stl` is a nice!nano v2 based on the model by Jordan Banasik (Woovie).
Source: https://github.com/Woovie/nicenano-v2-model (nice_nano.STL).
License: CC0 1.0 Universal (public domain), https://creativecommons.org/publicdomain/zero/1.0/

Used only in the 3D preview (not included in STL/STEP export).
File axes: X across the board (0…17.8), Y up (−0.2…3.1), Z along the board (0…33.8), USB socket on the +Z side.
Model rescaled (2026-11-06) to caliper measurements of the board: 17.8 × 33.8 mm including USB,
board 33.0 × 1.2 mm, USB-C seated in a notch in the board, flush with the board bottom, overhanging 0.8 mm,
3.3 mm thick overall (socket from −0.2 to 3.1, Y = 0 is the board bottom). Original Woovie model: board 33.10 × 0.8, USB overhang 1.52, 3.2 overall.
